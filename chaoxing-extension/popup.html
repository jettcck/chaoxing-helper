📖 新手教程：3 分钟拿到免费 API Key（点开）

三种方案任选其一。推荐方案 A——免费、国内直连、不用装任何软件。

方案 A · 智谱 GLM-4-Flash（免费，推荐）

  1. 打开 open.bigmodel.cn，右上角「注册/登录」，用手机号注册。
  2. 登录后按提示完成实名认证（免费，通常几分钟通过）。
  3. 左侧菜单进「API Keys」→「创建 API Key」→ 复制生成的 Key（形如 一串字符.一串字符，只显示一次，先存好）。
  4. 回到本弹窗：服务商选「智谱 GLM-4-Flash（免费）」，模型名保持 glm-4-flash，把 Key 粘进「API Key」框。
  5. 点「保存模型设置」→ 再点「测试连接」。出现「连接成功」即可开始答题。

方案 B · 本地 Ollama（免费、无需 Key、数据不出本机）

  1. 到 ollama.com/download 下载并安装。
  2. 打开命令行执行：ollama pull qwen2.5:7b（约 4.7 GB，首次较慢）。
  3. 服务商选「本地 Ollama」，「API Key」留空，保存设置 → 测试连接。

方案 C · DeepSeek（付费，便宜且答题较准）

  1. 到 platform.deepseek.com 注册 →「API Keys」→ 创建并复制。
  2. 服务商选「DeepSeek（付费）」，粘贴 Key，保存设置 → 测试连接。

常见问题

  • 提示 401 / 403：Key 没复制全或已失效，重新复制粘贴一次。
  • 提示 429：免费额度限流（智谱约 5 次/分钟）。等 1 分钟再试，或把「答错重试次数」调小以减少调用。
  • Key 会被上传吗？不会。Key 只保存在你本机浏览器（chrome.storage.local），仅用于直接请求你选的那家服务商，本插件不经过任何中间服务器。
  • 只想刷视频、不想答题？取消勾选「出现题目自动作答」，就无需配置 Key。

不会配置？点上方「📖 新手教程」按步骤来。免费方案：智谱 glm-4-flash 国内直连；本地 Ollama 可留空 Key。
